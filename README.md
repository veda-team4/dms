## DMS란 무엇인가?
DMS는 ***D***river ***M***onitoring ***S***ystem의 약자입니다. DMS는 대시보드에 장착된 카메라를 사용하여 운전자의 졸음을 감지하고, 이를 통해 운전자에게 오디오 경보와 경고등을 제공하여 집중력을 되찾도록 돕는 안전 시스템입니다.

이 프로젝트는 Raspberry Pi 4 Model B와 Raspberry Pi Camera Module 2를 사용하여 운전자의 눈이 감겨 있거나 머리가 숙여져 있는지를 실시간으로 감지합니다. 시스템이 졸음을 감지하면 LED와 스피커를 사용해 시각적, 청각적 경고를 제공하여 운전자를 깨웁니다.

추가적으로, 운전자가 졸음 상태임을 주변 차량에 알리기 위해 경고가 시작될 때 비상등도 동시에 켜집니다.

## 시스템 구조

### 하드웨어 구성
- **Raspberry Pi 4 Model B**
- **Raspberry Pi Camera Module 2**
- **LED (경고 표시)**
- **스피커 (경보음 출력)**
- **릴레이 모듈 (차량 비상등 제어)**

### 소프트웨어 구성
- **영상 처리 파이프라인**
  - OpenCV를 사용한 실시간 영상 입력
  - 얼굴 및 눈 랜드마크 추출 (dlib / MediaPipe / NCNN)
  - EAR(Eye Aspect Ratio) 계산 및 고개 숙임 감지
  - 졸음 여부 판단 알고리즘

- **알람 제어 로직**
  - 졸음 상태 감지 시 LED, 스피커 활성화
  - 비상등 제어 (GPIO + 릴레이)

- **멀티스레드 구조**
  - 카메라 캡처 스레드
  - 영상 분석 스레드
  - 알람 제어 스레드

## 설치 및 실행 방법

### 1. 환경 준비
- Raspberry Pi OS 설치
- OpenCV, dlib 또는 MediaPipe, NCNN 라이브러리 설치
- GPIO 제어를 위한 RPi.GPIO 라이브러리 설치
- 보안 OpenSSL 설치
- OSRM 요청에 필요한 curl

```bash
sudo apt update
sudo apt install python3-opencv python3-pip
pip3 install mediapipe RPi.GPIO
sudo apt-get install libssl-dev
apt install curl
apt install libcurl4-openssl-dev
```

### 2. 카메라 활성화
- 레거시 V4L2 카메라 모드 활성화
- #/boot/firmware/config.txt 설정 변경
```bash
camera_autodetect=0    # Unicam 오버레이 방지
start_x=1               # bcm2835-v4l2 드라이버 활성화
gpu_mem=256             # GPU 메모리 확보
```

위 내용을 맨 아래에 추가한 후 재부팅 후
아래와 같이 커넝 모듈 로드

```bash
sudo modprobe bcm2835-v4l2
```

다음 명령어로 영상 출력 확인 가능
```bash
ffplay /dev/video0
```

#### 홈
- 홈에서는 손을 뻗으면 다음 캠 세팅 메뉴로 넘어갈 수 있습니다.
  - 프로그램의 우측 하단에는 항상 안내문이 표시됩니다.

#### 캠 세팅 메뉴
- 캠 세팅 메뉴에서는 얼굴이 인식되고 있는지 카메라 화면의 우측 상단에서 확인이 가능합니다.
- 본인의 얼굴이 잘 인식되는 위치와 각도로 카메라를 조정합니다.
- 인식이 잘 되도록 한 후, 손을 뻗어 제스처 모드로 전환한 후 오른쪽 스와이프하여 다음 메뉴로 넘어갑니다.
  - 제스처 모드로 전환되면 카메라 화면에 점선으로 스와이프 영역이 표시됩니다.
  - 캠 세팅 메뉴, 눈 인식 메뉴, 모니터링 메뉴에서는 왼쪽 스와이프하여 이전 메뉴로 되돌아갈 수 있습니다.

#### 눈 인식 메뉴
- 눈 인식 메뉴에서는 얼굴과 눈, 코, 입이 인식됩니다.
- 눈을 뜬 상태에서 오른쪽 스와이프하면 뜬 눈의 크기를 인식합니다.
- 인식이 완료되면 알람음이 울리고, 그 후 오른쪽 스와이프하여 다음으로 넘어갑니다.

- 눈을 감은 상태에서 오른쪽 스와이프하여 감은 눈의 크기를 인식합니다.
- 인식이 완료되면 알람음이 울리고, 그 후 오른쪽 스와이프하여 다음으로 넘어갑니다.
  - 눈 인식 메뉴에서는 인식 도중 눈을 깜빡일 경우 정확도가 현저히 떨어집니다. 모니터링 메뉴에서 인식의 정확도가 떨어진다고 판단되면 왼쪽 스와이프로 눈 인식 메뉴로 돌아와 다시 인식하여 주시기 바랍니다.

#### 모니터링 메뉴
- 모니터링 메뉴가 되면 이제 졸음 감지를 시작합니다.
- 눈을 감을 경우 졸음도 퍼센트가 증가하고, 눈을 뜨면 감소합니다.
- 졸음도가 40% 혹은 80%에 도달하게 되면 중앙 관제 시스템에 해당 사실이 전송됩니다.
- 고개 떨어짐이 감지되거나 졸음도가 80%에 도달하게 되면 졸음 운전으로 판단하여 카메라 화면에 현재 위치에서 가장 가까운 휴게소 및 졸음 쉼터까지의 거리와 예상 소요 시간을 알려줍니다. 경광등이 깜빡이며 일어나라는 음성안내가 흘러나옴과 동시에 비상등이 켜집니다.
- 해당 경고 알람은 사용자가 알람을 끄기 전까지 유지됩니다.
- 카메라에 손을 뻗으면 경고 알람이 꺼지고 비상등도 함께 꺼집니다.
- 관제 시스템에서 메시지를 보내면 카메라 화면에 해당 내용이 표시됩니다.
- 운전을 끝마치면 손을 뻗어 제스처 모드로 변환한 후 오른쪽 스와이프하여 리포트 메뉴로 넘어갑니다.
